Case Study: Sistem Checkout Produk Sederhana
Program menerima tiga input: harga produk, jumlah produk, dan status member. Program kemudian menghitung subtotal, diskon, ongkos kirim, serta total pembayaran dengan aturan berikut.
1. Harga produk harus berupa angka positif dan jumlah produk harus berupa bilangan bulat positif. Jika tidak valid, program menampilkan pesan input tidak valid dan tidak melanjutkan perhitungan.
2. Subtotal = harga produk x jumlah produk.
3. Member mendapatkan diskon 10% dari subtotal. Non-member tidak mendapatkan diskon.
4. Setelah diskon, ongkos kirim gratis apabila total setelah diskon minimal Rp250.000. Jika kurang dari Rp250.000, ongkos kirim Rp15.000.
5. Total pembayaran = total setelah diskon + ongkos kirim.
Ketentuan Pengerjaan:
1. Tuliskan problem decomposition yang menjelaskan input, proses, output, dan aturan keputusan dari case study.
2. Buat flowchart yang memuat proses validasi input, perhitungan subtotal, keputusan status member, keputusan ongkos kirim, dan output total pembayaran.
3. Buat pseudocode yang konsisten dengan flowchart dan menjelaskan urutan proses dengan jelas.
4. Implementasikan pseudocode ke JavaScript melalui satu fungsi bernama hitungCheckout(harga, jumlah, isMember). Fungsi mengembalikan hasil perhitungan atau pesan error untuk input tidak valid.
5. Lakukan pengujian minimal pada delapan skenario: member, non-member, total di bawah Rp250.000, tepat Rp250.000, di atas Rp250.000, jumlah 0, jumlah pecahan, dan harga tidak valid.
6. Tidak perlu membuat UI, API, database, atau deployment. Fokus assignment adalah logika problem solving dan implementasi JavaScript dasar.
Deliverables
1. README.md berisi nama, deskripsi case study, cara menjalankan program, dan ringkasan penggunaan AI bila ada.
2. analysis.md berisi problem decomposition: input, proses, output, pattern, dan abstraction.
3. flowchart.drawio serta flowchart.png atau PDF hasil export.
4. pseudocode.md atau pseudocode.txt.
5. checkout.js.
6. testing.md atau testing.pdf yang memuat minimal delapan skenario uji beserta hasilnya.
