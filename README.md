# Mini Project: Sistem Checkout Produk Sederhana

**Nama:** Iroh Nurrohmah

## Deskripsi

Program JavaScript sederhana untuk menghitung total pembayaran produk berdasarkan harga, jumlah pembelian, dan status member. Member memperoleh diskon 10% dari subtotal. Ongkos kirim gratis jika total setelah diskon minimal Rp250.000; jika kurang, ongkos kirim sebesar Rp15.000. Harga harus positif dan jumlah harus bilangan bulat positif.

## Cara Menjalankan

Pastikan [Node.js](https://nodejs.org/) sudah terpasang. Dari folder proyek, jalankan:

```bash
node checkout.js
```

Program menjalankan contoh kasus checkout dan menampilkan hasilnya di terminal.
